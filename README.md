# Очередь заявок для Owlbear Rodeo

Игроки встают в очередь по горячей клавише, все видят порядок, мастер отмечает «выступил».

## Управление

- **Q** — встать в очередь (работает, пока окно Owlbear Rodeo в фокусе).
- **Shift+Q** — выйти из очереди.
- Те же действия есть кнопками в панели инструментов и в окне расширения.
- На иконке расширения виден значок с числом заявок.
- Мастер получает уведомление о каждой новой заявке и может нажать ✓ напротив игрока или «Очистить очередь».

## Размещение на GitHub Pages

1. Создайте публичный репозиторий и загрузите в него все файлы из этой папки.
2. В `manifest.json` замените `ВАШ_НИК` и `ИМЯ_РЕПОЗИТОРИЯ` (4 места).
3. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты откройте `https://ВАШ_НИК.github.io/ИМЯ_РЕПОЗИТОРИЯ/manifest.json` — должен показаться текст манифеста.
5. В Owlbear Rodeo: профиль → Extensions → Add Custom Extension → вставьте эту ссылку на манифест.

## Пересборка

Горячие клавиши меняются в начале `background.js`. После правки:

```
npm install
npm run build
```
